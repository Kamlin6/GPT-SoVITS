# ref/ — 参考音频标准

> 本文档定义了 GPT-SoVITS 零样本克隆中参考音频的录制/选择规范。
> 适用于 `ref/` 下所有角色目录。

## 目录结构

```
ref/
├── README.md              ← 本文件：全局标准
├── Civilight/
│   ├── audio/
│   │   ├── reference.wav  ← 日文参考音频
│   │   ├── clip_jp.wav    ← 原始素材（非参考音频，超10秒限制）
│   │   └── README.md      ← 该角色当前 ref 状态
│   └── text/
│       ├── reference.txt  ← 日文提示文本
│       └── README.md
└── Rimuru/
    ├── audio/
    │   └── rimuru_GPT.wav
    └── text/
        └── reference.txt
```

## 时长要求

| 级别 | 时长 | 说明 |
|------|------|------|
| **代码硬限制** | 3 ~ 10 秒 | 超出范围直接抛出 `OSError`，模型拒绝加载 |
| **官方建议** | 5 秒 | GPT-SoVITS 文档："Input a 5-second vocal sample" |
| **本项目推荐** | 5 ~ 8 秒 | 留余量但不浪费；过长不会提升音色还原度 |

> **注意**：参考音频长度在 3~10 秒范围内，对零样本克隆的音色还原度影响很小。
> 远不如录音质量和环境安静度重要。不要为了"更长"而牺牲清晰度。

## 音频质量要求

| 维度 | 要求 | 理由 |
|------|------|------|
| **背景噪音** | 尽量无（安静室内录制） | 噪音会被编码到 speaker embedding 中，影响合成干净度 |
| **混响** | 无（不要在大房间/走廊录制） | 混响同样污染音色特征 |
| **响度** | 正常说话音量，不要喊叫/耳语 | 模型自动做软削波，但极端动态范围会丢失信息 |
| **语音类型** | 纯语音（不是唱歌/喊叫/气声） | 模型训练数据是语音，非语音模式会导致异常 |
| **情感** | 中性偏自然，与角色基调一致 | 参考音频的情感会微妙影响合成输出的韵律倾向 |

## 内容要求

| 维度 | 要求 |
|------|------|
| **语言** | 参考音频的语言必须与其标注的语言一致（ja 音频配 ja 文本） |
| **内容** | 一句完整的话，不是单词列表或碎片音节 |
| **音素覆盖** | 尽量覆盖该语言常见音素，但**不强制**（零样本主要靠 speaker embedding，不需要穷举音素） |
| **语速** | 自然语速，不要刻意放慢或加快 |

## 格式

| 维度 | 要求 |
|------|------|
| **文件格式** | wav 推荐（无损），mp3/flac 等也可（自动解码） |
| **采样率** | 不限（16k/22.05k/44.1k/48k 均可，模型自动重采样） |
| **声道** | 单声道或立体声均可（立体声自动降混为单声道） |
| **位深** | 16-bit 推荐 |

## 文本配对

每个参考音频**必须**有配套的 `.txt` 文件，内容为音频中说的话：

```
ref/Civilight/audio/reference.wav  ← 音频
ref/Civilight/text/reference.txt   ← 文本：音频里说了什么
```

**规则**：
- 文本语言 = 音频语言（ja 音频 → ja 文本，zh 音频 → zh 文本）
- 文本内容 = 音频中实际说的话（逐字对应，不是翻译或概括）
- 一行即可，末尾不需要标点（模型会自动追加）

**示例**：
```
# reference.txt（日文）
テレジアはもう戻らぬ旅路に着いたわ。残された私は、文明の存続の
```

## 命名约定

| 模式 | 格式 | 示例 |
|------|------|------|
| 单语言参考（默认） | `reference.wav` + `reference.txt` | 日文 |
| 追加语言参考 | `reference_{lang}.wav` + `reference_{lang}.txt` | `reference_zh.wav` |
| 原始素材（非参考） | 自由命名 | `clip_jp.wav`、`raw_source_01.wav` |

> **区分参考音频和原始素材**：参考音频是送给 TTS 模型的 3~10 秒片段；
> 长于 10 秒的原始录音是素材，不属于参考音频，不要放入 `refs` 配置中。

## 添加新参考音频的步骤

1. **录制/选取**一段 5~8 秒的目标语言音频，满足上述质量要求
2. **保存**到 `ref/{角色}/audio/reference_{lang}.wav`
3. **创建**配套文本 `ref/{角色}/text/reference_{lang}.txt`，写入音频内容
4. **更新** `config.json` 中的 `refs`：
   ```json
   "zh": {
     "audio": "ref/Civilight/audio/reference_zh.wav",
     "text": "ref/Civilight/text/reference_zh.txt"
   }
   ```
5. **更新** `enabled_languages`（如从 `["ja"]` → `["ja", "zh"]`）
6. **测试**运行 morning pipeline，确认不报错且输出音频音色可接受

## 常见陷阱

| 陷阱 | 现象 | 解决 |
|------|------|------|
| 参考音频超过 10 秒 | `OSError: 参考音频在3~10秒范围外，请更换！` | 用 Audacity/ffmpeg 裁剪 |
| 参考音频短于 3 秒 | 同上 | 换更长的片段 |
| 文本语言与音频不匹配 | 合成音色走样 | 确保 .txt 内容 = 音频实际说的话 |
| 用了原始素材当参考 | 报错或音色异常 | `clip_jp.wav`（23s）不是参考音频，裁剪后使用 |
| 参考音频有背景音乐 | 合成输出带奇怪音色 | 重新录制干净音频 |
| 缺少提示文本 | v2ProPlus 不强制但推荐提供；v3/v4 会报错 | 始终配 .txt |
